# 🎈 놀이터 – 아이들이 코드로 모여 함께 노는 웹 게임

아이들이 **한 번만 입장**하면, 방을 나가지 않고 **🧩 퍼즐**과 **📖 말씀 블록**을 차례로 함께하는 웹 게임입니다.

- 플레이어: `/play/` (관리자 화면의 QR로 접속)
- 관리자: `/play/admin.html`
- 예전 주소 `/puzzle/`, `/verse/`는 새 주소로 자동 이동합니다.

### 진행 순서
1. 관리자가 로그인하고 **방 만들기**를 누르면 QR과 입장 코드가 나옵니다.
2. 아이들이 QR로 들어와 이름·비밀번호 4자리를 정하고 그룹을 고릅니다. 입장은 **한 번만** 합니다.
3. 관리자가 **이번 게임**(🧩 퍼즐 / 📖 말씀 블록)을 고르고 설정한 뒤 시작합니다. 아이들 대기 화면에는 '다음 게임: …'이 미리 보입니다.
4. 게임이 끝나면 **다음 게임 준비**를 누릅니다. 아이들은 대기 화면으로 돌아가고, 다른 게임을 골라 바로 이어서 할 수 있습니다. 그룹, 그룹 이름, 올린 사진, 구절 목록은 그대로 유지됩니다.
5. 서버가 다시 시작되어 방이 사라지면 관리자와 아이들 모두에게 안내가 나옵니다. 관리자는 새 방을 만들면 됩니다.

## 인터넷에 올리기 (추천 · 무료, 한 번만 하면 됨)

QR을 찍은 휴대폰이 어디서든 들어오려면 인터넷 주소가 필요합니다.

1. 이 폴더를 GitHub 저장소로 올립니다.
2. https://render.com 에 GitHub 계정으로 가입 → **New → Blueprint** → 저장소 선택 (`render.yaml`을 자동으로 읽음)
3. Render 서비스의 **Environment**에 `ADMIN_PASSWORD`(관리자 비밀번호)를 추가합니다.
4. 몇 분 뒤 `https://kids-game-hub-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소로 들어가 방을 만들면 QR이 이 주소로 만들어집니다.

> 무료 요금제는 15분 동안 아무도 접속하지 않으면 잠들어서, 다음 첫 접속은 30초~1분 걸립니다. 수업 전에 한 번 열어 두면 됩니다.

## 내 PC에서 실행 (같은 와이파이에서만)

```bash
npm install
npm start          # http://localhost:3000
npm test           # 퍼즐·말씀 블록·통합 세션 시나리오 테스트 (서버가 켜져 있어야 함)
node test/load.js 50 8 5 7 mixed   # 퍼즐 부하 테스트: 50명·8그룹·5×7 퍼즐
node test/verse-load.js 50 8 submit # 말씀 블록 부하 테스트: 50명·8그룹·B 방식
```

PC에서 localhost로 열어도 QR에는 PC의 내부 IP가 자동으로 들어가므로, 같은 와이파이의 휴대폰은 QR만 찍으면 됩니다. 주소를 직접 정하려면 `PUBLIC_URL=https://내주소 npm start`.

## 🧩 퍼즐

### 관리자 ('이번 게임'에서 🧩 퍼즐)
1. 관리자 비밀번호로 로그인 → **방 만들기** (방은 관리자만 만들 수 있음). 비밀번호는 환경 변수 `ADMIN_PASSWORD`로 정합니다. 기본값은 `admin`입니다.
2. 방의 **QR 코드**와 입장 코드를 보여 줍니다. 'QR 크게 보기'로 교실 화면에 띄울 수 있습니다.
3. 퍼즐 크기(가로 × 세로, 2~8칸), 조각 모양(네모/세모/섞어서), 그룹 수(1~10)를 정하고 **사진을 첨부**합니다. 첨부한 사진은 방의 '올린 사진' 목록(최대 12장)에 임시로 보관되어, 다음 판에도 다시 올리지 않고 고를 수 있습니다.
4. **그룹 이름**을 눌러 바꿀 수 있습니다(예: 1그룹 → 호랑이팀).
5. **친구 조각 투명도**(10~100%)를 정합니다. 게임 중에도 바꿀 수 있습니다.
6. 플레이어가 고른 그룹이 전체 화면에 실시간으로 보입니다. 접속 상태가 표시되고, 다른 그룹으로 옮기거나 내보낼 수 있습니다.
7. 게임 중에는 그룹별 판이 실시간으로 채워집니다. 조각을 맞출 때마다 **띠링** 소리가 나고, 그룹이 완성되면 순위가 나옵니다.
8. **💡 전체 힌트** 버튼을 누르면 모든 플레이어 판에 사진이 흐리게 보입니다. 기본값은 꺼짐입니다.
9. 새로고침해도 같은 방을 이어서 관리할 수 있습니다.

### 플레이어
1. 입장 코드를 확인한 다음 **이름과 비밀번호 4자리**를 정합니다. 나갔다가 같은 이름과 비밀번호로 들어오면 그룹과 조각이 그대로 있습니다. 새로고침하면 자동으로 다시 들어옵니다.
2. 그룹을 고르고 **결정**을 누르면 확인 창이 뜹니다. **수락**하면 그룹이 확정되고 관리자 화면에 이름이 나타납니다. 확정한 그룹은 바꿀 수 없습니다.
3. 게임이 시작되면 그룹의 조각을 멤버들이 똑같이 나눠 갖습니다. 조각은 처음에 돌아가 있으며, **두 번 누르면 90°씩 돌아갑니다**.
4. 조각은 판 위 **아무 곳에나 올려 둘 수 있고**, 같은 그룹 친구 화면에 이름표와 함께 반투명하게 보입니다. 그래서 서로 이야기하면서 맞출 수 있습니다. 자리와 방향이 모두 맞으면 고정되고, 판 위에서 두 번 눌러 돌려도 됩니다. 판 밖에 놓으면 다시 쟁반으로 돌아갑니다.

## 📖 말씀 블록

### 관리자 ('이번 게임'에서 📖 말씀 블록)
1. 관리자 비밀번호로 로그인 → **방 만들기** → QR과 입장 코드를 보여 줍니다.
2. **구절 추가**: 본문과 참조(예: 요한복음 15:5)를 넣습니다. 띄어쓰기마다 블록이 나뉘고, `/`를 넣으면 그 기준으로 나뉩니다(블록 최대 30개). 구절은 방에 최대 20개까지 임시로 보관되어 라운드마다 골라 쓸 수 있습니다.
3. **확인 방식**을 고릅니다.
   - **A. 칸마다 바로 확인**: 맞는 칸에 넣으면 바로 고정됩니다.
   - **B. 다 채우고 제출**: 틀리면 틀린 개수만 알려 주고, 5초 뒤에 다시 제출할 수 있습니다.
4. 게임 중에는 그룹별 문장 줄이 실시간으로 채워지고, 블록이 고정될 때마다 띠링 소리가 납니다. 힌트로 **참조 보여주기**와 **첫 글자 보여주기**를 쓸 수 있고, **구절 크게 보기**로 교실 화면에 구절을 띄울 수 있습니다.
5. **다음 라운드 준비**를 누르면 그룹과 구절 목록은 그대로 둔 채 대기실로 돌아갑니다.

### 플레이어
- 입장, 이름 + 비밀번호, 그룹 선택은 퍼즐과 같습니다.
- 그룹마다 구절 블록을 멤버들이 나눠 갖습니다. **내 블록을 누르고 빈칸을 누르거나**, 빈칸으로 **끌어다 놓으면** 들어갑니다. 칸에 넣은 블록은 같은 그룹 친구 화면에도 보입니다. 칸에 있는 내 블록을 누르면 다시 빠집니다.
- 같은 단어가 두 번 나오면 서로 바꿔 넣어도 정답입니다. 블록보다 멤버가 많으면 블록이 없는 친구는 도우미 안내를 받습니다.

## 구조

```
server.js                     Express + Socket.IO, /play 네임스페이스 하나, QR API
games/session/server.js       통합 세션: 방·관리자·플레이어·그룹·재입장·접속 표시, 게임 선택·시작·다음 게임 준비
games/puzzle/game.js          퍼즐 모듈 (조각 분배, 판 위 올려 두기, 회전·정답 판정, 사진 목록)
games/verse/game.js           말씀 블록 모듈 (블록 분배, A/B 확인 방식, 힌트, 구절 목록)
games/verse/logic.js          말씀 블록 블록 나누기·정답 판정 규칙
public/index.html             허브(메인 화면)
public/play/                  통합 화면: index.html·player.js(플레이어), admin.html·admin.js(관리자),
                              게임별 화면 puzzle-player.js·verse-player.js·puzzle-admin.js·verse-admin.js
public/puzzle/                공통 디자인 theme.css, 공통 도구 core.js, 기본 그림 presets.js (+ 예전 주소 이동 페이지)
public/verse/                 예전 주소 이동 페이지
test/session-helpers.js       테스트 공통 도구
test/puzzle-sim.js            퍼즐 시나리오 테스트
test/verse-logic.js           말씀 블록 판정 규칙 테스트
test/verse-sim.js             말씀 블록 시나리오 테스트
test/session-sim.js           통합 세션 테스트 (퍼즐↔말씀 전환, 재입장 없음)
test/load.js, test/verse-load.js   50명 동시 접속 부하 테스트
docs/superpowers/             설계 문서·구현 계획
```

## 새 게임 추가하기

1. `games/<게임>/game.js`에 게임 모듈을 만듭니다. 필요한 함수는 `games/session/server.js` 머리말과 `games/puzzle/game.js`를 참고하세요: `createState`, `start`, `groupView`, `roundView`, `playerStats`, `onKick`, `onReset`, `adminEvents`, `playerEvents`.
2. `server.js`의 `registerSession(io.of('/play'), { … })`에 모듈을 추가합니다.
3. `public/play/<게임>-player.js`(`window.PlayGames.<게임>`)와 `public/play/<게임>-admin.js`(`window.AdminGames.<게임>`)를 만들고, `index.html`·`admin.html`에 화면 영역과 '이번 게임' 탭을 추가합니다.
