# 🎈 놀이터 – 아이들이 코드로 모여 함께 노는 웹 게임

여러 게임을 담는 웹 게임 허브와 첫 번째 게임 **함께 맞추는 퍼즐**이 들어 있습니다.

## 인터넷에 올리기 (추천 · 무료, 한 번만 하면 됨)

QR을 찍은 휴대폰이 어디서든 들어오려면 인터넷 주소가 필요합니다.

1. 이 폴더를 GitHub 저장소로 올립니다.
2. https://render.com 에 GitHub 계정으로 가입 → **New → Blueprint** → 저장소 선택 (`render.yaml`을 자동으로 읽음)
3. 몇 분 뒤 `https://kids-game-hub-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소로 들어가 방을 만들면 QR이 이 주소로 만들어집니다.

> 무료 요금제는 15분 동안 아무도 접속하지 않으면 잠들어서, 다음 첫 접속은 30초~1분 걸립니다. 수업 전에 한 번 열어 두면 됩니다.

## 내 PC에서 실행 (같은 와이파이에서만)

```bash
npm install
npm start          # http://localhost:3000
npm test           # 5명이 동시에 퍼즐을 맞추는 시뮬레이션 (서버가 켜져 있어야 함)
```

PC에서 localhost로 열어도 QR에는 PC의 내부 IP가 자동으로 들어가므로, 같은 와이파이의 휴대폰은 QR만 찍으면 됩니다. 주소를 직접 정하려면 `PUBLIC_URL=https://내주소 npm start`.

## 함께 맞추는 퍼즐

1. 방장이 이름을 쓰고 **새 방 만들기**를 누르면 4자리 방 코드가 생깁니다.
2. 친구들은 화면의 **QR을 찍으면** 이름만 쓰고 바로 들어옵니다. 방 코드를 직접 입력하거나 링크로 들어와도 됩니다. ('크게 보기'로 교실 화면에 QR을 크게 띄울 수 있음) 한 방에 최대 12명까지 들어올 수 있습니다.
3. 방장이 사진(기본 그림 3장 또는 직접 올린 사진), 조각 모양(네모 / 세모 / 섞어서), 크기(2×2~8×8)를 고릅니다.
4. 게임을 시작하면 조각이 섞여 사람 수만큼 똑같이 나뉩니다. 예를 들어 5×5 네모 퍼즐(25조각)을 5명이 하면 1명당 5조각입니다.
5. 각자 자기 조각만 판으로 끌어다 놓습니다. 정답 근처에 놓으면 제자리에 붙고, 모든 친구 화면에 바로 나타납니다.
6. 모든 조각을 맞추면 걸린 시간과 사람별로 맞춘 조각 수가 나옵니다.

- **세모**: 한 칸을 대각선으로 나눠 두 조각으로 만듭니다. 그래서 5×5 퍼즐은 50조각이 됩니다.
- **섞어서**: 칸마다 네모 또는 세모 두 개가 무작위로 정해집니다.
- 게임 도중에 나간 친구의 남은 조각은 남은 친구들에게 다시 나눠집니다.
- 정답 판정은 서버가 하므로 다른 사람의 조각을 놓거나 위치를 속일 수 없습니다.

## 구조

```
server.js                 Express + Socket.IO, 게임별 네임스페이스 등록
games/puzzle/server.js    방/세션, 조각 생성·분배, 정답 판정
public/index.html         게임 허브(메인 화면)
public/css/common.css     공통 스타일
public/puzzle/            퍼즐 화면 (index.html, puzzle.js, puzzle.css, presets.js)
test/sim.js               멀티플레이 시뮬레이션
```

## 두 번째 게임 추가하기

1. `games/<게임이름>/server.js`에 `module.exports = nsp => { ... }` 형태로 서버 로직을 만듭니다.
2. `server.js`에서 `register<게임>(io.of('/<게임이름>'))`로 등록합니다.
3. `public/<게임이름>/`에 화면을 만들고 `io('/<게임이름>')`로 접속합니다.
4. `public/index.html`의 "준비 중" 카드를 링크로 바꿉니다.

## 참고

- 방 정보는 서버 메모리에만 저장되므로 서버를 다시 켜면 모든 방이 사라집니다.
- 외부에 공개하려면 Render, Railway, Fly.io처럼 WebSocket을 지원하는 Node 호스팅에 올리면 됩니다.
